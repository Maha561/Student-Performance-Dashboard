
# 🎓 Student Performance Dashboard

A simple and interactive web application to manage and analyze student performance.

This project allows users to add, view, filter, and analyze student data with a clean dashboard and visual insights.

--------------------------------------------------

🚀 Features

- 🔐 Login Authentication (LocalStorage based)
- ➕ Add Student Details
- 📊 Dashboard (Total, Pass, Fail)
- 🔍 Search by Name
- 🎯 Filter by Department
- 📉 Pie Chart Analytics (Pass vs Fail)
- 🌙 Light / Dark Theme
- 🗑️ Delete Student Records

--------------------------------------------------

🛠️ Tech Stack

- HTML
- CSS
- JavaScript
- Chart.js
